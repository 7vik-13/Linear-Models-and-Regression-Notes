## Linear Models & Regression Notes

This repository contains `.tex`, `.pdf` and `.sty` files for notes from the course _Introduction to Linear Models and Regression_, a 4th-semester B.Math course at ISI Bangalore. The `.sty` file contains the custom LaTeX styling used to typeset the notes.

The notes are based on the source material by Prof. Moutushi Chatterjee. The visuals and colour scheme are heavily based on [NotesTex](https://github.com/Adhumunt/NotesTeX).

> **Please note:** These notes are __not exhaustive and may contain errors__. Any errors or inaccuracies are my own. Use them with caution and refer to the original source material when necessary.

### Features
- Visually appealing
- Extensive references to equations
- Explanations for implications wherever necessary
- No footnotes, to maintain the flow of the notes
